# Aegis Marine Shipmanagement

> Aegis Marine Shipmanagement Inc. is a privately owned marine vessel transportation and ship
> management company headquartered in Georgetown, Guyana, founded in 2018 by Sean Clarke. It
> manages crude oil tankers, LNG tankers and offshore support vessels for third-party owners,
> covering commercial, technical, safety and quality, and logistics ship management, plus vessel
> registration, technical inspection, chartering and crew management.

**This company does not sell an API.** It publishes no developer portal, no API documentation, no
SDKs and no product API. The only machine-readable interface it exposes is the WordPress core REST
API behind its corporate website, which serves the marketing site's own pages, media and taxonomy.
There is no vessel, voyage, charter, port or crew data on any public surface.

## Working with this API

- **Auth**: none. Anonymous read only. No signup, no key, no OAuth. `/wp/v2/users` and
  `/wp/v2/settings` return HTTP 401; `/contact-form-7/v1/contact-forms` returns HTTP 403.
- **Writes**: none available. POST/PUT/PATCH/DELETE are registered by WordPress core but closed to
  the public, and no credential can be obtained.
- **Pagination**: `page` and `per_page` (maximum 100 — above it, HTTP 400 `rest_invalid_param`).
  Totals arrive in the `X-WP-Total` and `X-WP-TotalPages` headers; `Link` carries `rel="next"`.
- **Payload trimming**: use `_fields=id,slug,title,link` — full records carry a large `yoast_head`
  HTML blob.
- **Errors**: `{"code": "...", "message": "...", "data": {"status": 404}}` as `application/json`.
  Not RFC 9457 problem+json.
- **Rate limits**: none published and no rate-limit headers returned. A Wordfence installation may
  throttle at the edge without notice.
- **Freshness**: content is static. Every page was last modified between 2018 and 2019, the newest
  media dates from 2019-05-20, and there are zero posts and zero comments. Quote the `modified`
  field when presenting anything read here.
- **Not served**: no `/.well-known/security.txt`, `openid-configuration`, `oauth-authorization-server`,
  `api-catalog`, `ai-plugin.json`, `agent-card.json` or `agent.json` on any host (all HTTP 404). No
  MCP server, no GraphQL, no AsyncAPI, no webhooks, no status page, no changelog, no SDKs.
